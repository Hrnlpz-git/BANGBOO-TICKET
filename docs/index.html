01 / EL PROYECTO

Detrás de cada
concierto, hay un
sistema.

BANGBOO-TICKET es un sistema de escritorio diseñado para apoyar la venta local de boletos para conciertos y eventos musicales.

Centraliza la administración de eventos, artistas, localidades e inventario, mientras facilita el registro de ventas y la validación de entradas. Todo desde una misma aplicación.
